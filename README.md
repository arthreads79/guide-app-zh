# guide-app-zh

本仓库用于归档和发布多个独立的 HTML 页面。这些页面以静态文件形式存放，不依赖于特定后端服务，可以直接通过浏览器或静态托管平台访问。

## 项目简介

这是一个以中文内容为主的 HTML 页面集合仓库。每个页面都是独立、自包含的，适用于信息展示、工具页面、参考文档等场景。仓库不针对任何特定网站或域名，仅作为页面文件的归档与发布空间。

## 目录说明

```
guide-app-zh/
├── pages/          # 存放各个独立 HTML 页面
├── assets/         # 公共资源（如样式、脚本、图片等）
├── README.md       # 本文件
└── index.html      （可选）仓库首页或导航页
```

- `pages/`：每个 HTML 文件为一个独立页面，文件名建议反映页面内容主题。
- `assets/`：页面引用的外部资源文件，按类型或用途组织。

## 页面归档说明

- 每个 HTML 页面均为完整、自包含的文档，可直接双击打开或部署至任意静态服务器。
- 页面之间无强关联，可单独使用。
- 页面内容以中文为主，部分可能包含少量英文术语或代码片段。
- 页面不收集用户信息，不包含跟踪或分析脚本。

## 维护说明

- 新增页面：将 HTML 文件放入 `pages/` 目录，如有公共资源请放入 `assets/`。
- 更新页面：直接修改对应文件，注意保持与其他页面或资源的兼容性。
- 删除页面：移除对应文件，并检查是否有引用该页面的链接需要更新。
- 建议为每个页面在文件头部添加简要注释，说明页面用途、更新日期等信息。

## 使用方式

1. 克隆本仓库到本地。
2. 直接打开 `pages/` 下的 HTML 文件，或使用任意静态服务器（如 `python -m http.server`）预览。
3. 也可将整个仓库部署至支持静态页面的托管平台。
